AutoPodTranscript

播客逐字稿转换器 · 本地归档 · 云端同步 · AI 转录

AutoPodTranscript 是一套自动化播客处理流水线。通过 RSS 源批量下载播客音频到本地，可选同步至 Google Drive，并接入本地或云端 AI 生成逐字稿，作为「听觉笔记系统」的前置引擎。

核心特性

💾

本地优先归档

音频持久化保存，目录清晰，支持本地播放器与 NAS 归档。

🧩

模块化流水线

下载、云端同步、AI 转录解耦，可仅下载或全流程自动化。

⚡️

极速并发

多线程并发下载，智能增量更新，跳过已存在文件。

🔗

代理兼容

针对国内网络优化，支持配置代理连通海外源与 Google 服务。

快速开始

# 安装依赖
pip install -r requirements.txt

# 编辑 autopod.py 顶部配置（RSS 地址、保存路径、GDrive 等）后运行
python autopod.py

详细说明见 README.md · 使用云端同步时请勿将 client_secrets.json / token.json 提交至公开仓库
